## 1. ¿Qué es Markdown?
[cite_start]Markdown es un lenguaje de marcado ligero que permite añadir elementos de formato a documentos de texto plano[cite: 4, 5]. [cite_start]Fue creado por John Gruber en 2004 y su objetivo principal es la legibilidad[cite: 6, 9]. [cite_start]La idea es que un documento se pueda publicar tal cual, como texto plano, sin que parezca que se le han añadido etiquetas complejas[cite: 10].

### Características principales:
* [cite_start]**Versatilidad:** Usado para crear sitios web, notas, libros y documentación técnica[cite: 11].
* [cite_start]**Portabilidad:** Los archivos pueden abrirse en casi cualquier aplicación y migrarse fácilmente entre plataformas[cite: 12].
* [cite_start]**Independencia:** Funciona en cualquier dispositivo y sistema operativo[cite: 13].
* [cite_start]**A prueba de futuro:** El contenido puede leerse siempre con un editor de texto simple[cite: 14].

## 2. Metodología para la entrega en GitHub
Para subir este documento al repositorio de la actividad, se siguió el siguiente proceso técnico:

1. [cite_start]**Creación del archivo:** Se generó el archivo `markdown.md` asegurando que el tipo de archivo fuera "All Files (*.*)" para evitar la extensión `.txt`[cite: 59, 60].
2. **Sintaxis utilizada:**
   * [cite_start]**Encabezados:** Uso de `#` para títulos y `##` para secciones[cite: 17, 18, 19].
   * [cite_start]**Formato de texto:** Uso de `**` para resaltar nombres de archivos importantes[cite: 22].
   * **Tablas:** Organización del historial de cambios mediante columnas separadas por `|`[cite: 48, 49].
3. **Comandos de Git:**
   * `git clone https://github.com/xtaquiroo-dev/repositorio.git` para obtener el repo localmente.
   * `git add markdown.md` para preparar el archivo.
   * [cite_start]`git commit -m "Se añadio el primer archivo"` para registrar el progreso[cite: 90].
   * `git push origin main` para publicar en la plataforma.
